# **## Setup**

##### 

##### **1. Clone the repository.**

##### **2. Install dependencies:**

##### 

##### **```bash**

##### **pip install -r requirements.txt**

##### **```**

##### 

##### **3. Create a `.env` file:**

##### 

##### **```**

##### **GEMINI\_API\_KEY=your\_api\_key\_here**

##### **```**

##### 

##### **4. Run the notebook.**
